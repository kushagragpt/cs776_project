# Cross-Attention-Based Image Denoising

## Overview

This repository contains the implementation for a hybrid image denoising project developed as part of CS776 at IIT Kanpur. The approach leverages both classical Total Variation (TV) filtering and modern deep learning methods—specifically, a UNet architecture enhanced with cross-attention mechanisms. The goal is to produce high-quality denoised images by combining a TV-denoised “hint” image with a neural network model trained to further clean noisy images.

## Key Features

- **TV Denoising (tv.py):**  
  Applies Total Variation denoising to images to create “hint” versions that preserve edges while removing noise.

- **Hybrid Denoising Model (model.py):**  
  - Utilizes a UNet architecture optimized for image denoising.
  - Integrates cross-attention modules, enabling the model to use TV-denoised hints while denoising the noisy image.
  - Designed for iterative, multi-pass refinement to further improve results.

- **Custom Loss Functions:**  
  - Combines Mean Squared Error (MSE), Perceptual loss (VGG features), Structural Similarity (SSIM), TV loss, and Gradient loss.
  - Ensures both pixel accuracy and perceptual quality.

- **Benchmarks & Metrics:**  
  - Scripts for quantitative evaluation using PSNR and SSIM metrics.
  - Achieves +1.0 to +1.5 dB PSNR and ~17% SSIM gain over baselines.

## Directory Structure

- `tv.py`: TV denoising script for preprocessing images to create hint images.
- `model.py`: Model architecture, loss functions, data loaders.
- `benchmark_tv.py`, `benchmark_unet.py`, `benchmark_unet_patch.py`: Evaluation and benchmarking scripts for different models and approaches.
- `DIV2K_valid_HR/`, `DIV2K_train_HR/`: Datasets and processed images.
- `model_outputs_eval/`, `validation_outputs/`: Results and exports during benchmark.

## Usage

### 1. Run TV Denoising Preprocessing

Preprocess images with TV denoising to generate hint images:
```bash
python tv.py
```
This script saves denoised images and generates image mapping files for training and validation.

### 2. Train the UNet Model

Train the hybrid UNet with cross-attention:
```bash
python model.py
```
Adjust paths in the script as needed for your data locations.

### 3. Benchmark and Evaluate

Run benchmarking scripts to evaluate PSNR, SSIM, and output images:
```bash
python benchmark_tv.py
python benchmark_unet.py
python benchmark_unet_patch.py
```
Results will be saved in the `model_outputs_eval` and `validation_outputs` folders.

## Data Preparation

- Download and place the DIV2K dataset into `DIV2K_valid_HR` and `DIV2K_train_HR` folders.
- TV-denoised outputs and JSON mapping files are generated by `tv.py`.

## Model Details

- **UNet**: Encoder-decoder structure with skip connections for fine feature propagation.
- **Hint Encoder**: Extracts feature representations from TV-denoised images.
- **Self-Attention Encoder**: Enhances image features using patch-based attention.
- **Loss Function**: Combines multiple objectives (see `model.py`, `CombinedLoss` class).

## Results

- Achieved significant improvements in denoising performance:
  - **PSNR Gain:** +1.0 to +1.5 dB
  - **SSIM Gain:** ~17%
- The hybrid cross-attention method consistently beat classical and standard deep learning baselines.
